# Full paired SFP simulation evidence (2026-10-02)

ModelSim SE-64 10.6e, PowerShell. All added work is in this directory;
no production RTL, constraints, DMA, top, IP or PDS was edited.

The bench sends two 1280x480 merged frames: each row is 640 CAM5 pixels
then 640 CAM6 pixels, continuous DE, HS=0, followed by 648 blank clocks
(merge snapshot copy plus gap). Each camera therefore supplies 307200 pixels
per frame. Patterns distinguish camera, frame, row and column. TX uses the
actual `ov5640_sfp480p_test/ov5640_sfp480p_test/source/rtl/sfp_video_tx.v`.
The merge-shaped stimulus is generated by the bench, not cam2_merge RTL.

Clocks: video 62.5 MHz derived from TX fabric falling edges exactly like TX
top; TX fabric 125 MHz; RX 125 MHz with independent phase; AXI 131.25 MHz.
The configuration explicitly binds the TX FIFO to the TX source library and
the splitter FIFOs to the production RX source library. Scoreboards sample
pre-edge values, as downstream synchronous logic does.

| Case | CAM5/CAM6 pixels per frame | SOF per camera | Result |
| --- | --- | --- | --- |
| actual selected TX | 307200 / 307200 | 2 / 2 | PASS, zero errors |
| actual TX plus parallel GE skip/idle model | 307200 / 307200 | 2 / 2 | PASS, zero errors |
| alternate CTC TX, reset at 109 ns | 230400 / 230400 | 2 / 2 | FAIL, 25% missing and reordered pixels |
| alternate CTC TX, simulation-only read gating | 307200 / 307200 | 2 / 2 | PASS, zero errors |

Passing runs decode 1228800 pixels total, split 614400 per camera across two
frames, decoder maximum occupancy 2 symbols, and 184624 empty AXI cycles
per camera. TX and splitter full flags and decoder overflow are checked.
Logs are `actual.log`, `ge.log`, `ctc.log`, `ctc_fixed.log`.

The GE test preserves every actual TX data word and changed state control.
It replaces only redundant controls with legal K28.5/D28.2 skip words
(`28BC28BC`, K=0101) or K28.5/D5.6 idle words (`C5BCC5BC`, K=0101).
It processed 462766 skip and 462765 idle words without corrupting frames.
This checks decoder ignore semantics; it does not emulate HSST, GE LSM,
elastic buffer clock correction, comma alignment, bit errors, DDR or DMA.
The actual selected TX emits no explicit `28BC28BC` skips. Its state controls
contain K28.5/D28.2 in bytes 0/1; physical GE compatibility cannot be decided
from this parallel test.

## Confirmed alternate-source defect

`sfp_video_tx_ctc.v` defines `fifo_pop_gated` and pauses its packer at phase 6,
but connects FIFO `rd_en` to ungated `fifo_pop`. A nonempty FIFO thus advances
without the packer consuming the head on each skip cycle. Reset at 101 ns
happened to place skips on empty FIFO cycles and passed; reset at 109 ns
reproduces loss at the actual clock ratio. Decoder receives 921600 rather
than 1228800 pixels; each camera frame has 230400 rather than 307200.
Instrumentation records 462765 FIFO reads during skipped packer cycles,
including exactly 307200 active pixels discarded across both merged frames.

The `ctc_fixed` case forces FIFO `rd_en` to `!fifo_empty && ctc_phase!=6`
only in simulation; all expected pixels return, with zero skipped FIFO pops.
The corresponding proposed RTL correction is to connect FIFO `rd_en` to
the gated read enable, but no production edit was made.

The main TX `.pds`, backup `.pds` and `build.pds` all select `sfp_video_tx.v`,
not `sfp_video_tx_ctc.v`. Therefore this confirmed alternate-file defect is
not established as the current board freeze cause. The currently selected
TX -> decoder -> splitter passes at full size under ideal word transport.
Build155820 board diagnostics and the separate timing investigation remain
necessary to locate failure before or after this tested path.

## Reproduce

From the workspace root:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File project/sim/sfp_full/run.ps1 -Case actual
powershell -NoProfile -ExecutionPolicy Bypass -File project/sim/sfp_full/run.ps1 -Case ge
powershell -NoProfile -ExecutionPolicy Bypass -File project/sim/sfp_full/run.ps1 -Case ctc
powershell -NoProfile -ExecutionPolicy Bypass -File project/sim/sfp_full/run.ps1 -Case ctc_fixed
```

`ctc` intentionally exits nonzero. Other cases require both successful
simulation exit and `TB_PASS full` in their log. Each run covers 29.617 ms
of simulated time and takes approximately 15 seconds on this workstation.
