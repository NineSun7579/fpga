# 用户最新范围：以实际功能交付为准

用户明确“保证功能正常就可以了”，要求停止将交付无限扩展为工具内部完全形式证明。最终目标仍为生成新bit、SRAM烧录、RK3568截图与实际正常运行验证；未授权Flash。

后续优先完成必要构建和时序检查、真实SRAM编程/DONE、六路相机/RAW模型/motion/viewer运行、帧进展、错误日志和至少两组截图。正常结论必须来自当次实际板上证据；旧MP4画面不算。

已有内部bank、primitive行为、alias、CDB等调查保留，但不再仅因缺少工具内部完整形式证明而无限阻塞实测。完整原生IO引脚/电气报告与既有工作基线的一致性、实际映射/路由结果可作为必要工程判断依据。未知真实功能差异、明显错误约束和真实同域时序违例仍需处理，不能改报告或伪造PASS。

不扩大恢复证明范围，不新增AXI idle证书。保持已授权SRAM及既有正常恢复入口，当前正在执行的操作必须安全收尾并保留日志。优先将已有可用产物推进到新clock真实路由和板级验证，不再启动额外纯证明子任务。旧失败不删除，最终实际运行失败如实定位和修复。
