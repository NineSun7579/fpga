# 全命名空间接口发现

第一轮仅查询部分命令模式。本轮遍历全部Tcl命名空间并保存完整命令清单，对确实存在的export_fdc、.switch_db和集合查询接口仅请求帮助。不加载数据库、不导出设计、不生成报告或bit，也不修改冻结输入。

官方QCH帮助：Design Suite §3.4.2说明IO Report随PNR生成；§export_fdc说明dev_map后PCF反标约束导出，但未承诺BANK信息。PCE §3.4 I/O Table有BANK字段，属于约束表语义，不能直接代替routed内部配置验证。

本轮在map07退出后执行，采用与第一轮相同的单实例互斥/空闲保护和哈希回执。启动架构但未加载设计时的发现不能排除加载后才注册的接口；若仍无受支持接口，后续必须单独核实安全的design加载途径，不能把缺少查询解释为IO PASS。
