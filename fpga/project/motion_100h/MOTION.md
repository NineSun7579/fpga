# 100H 本地四路分块运动检测候选工程

本目录以当前六路采集版本 `192245` 为基线，仅为本板 CAM1–4 独立构建运动检测旁路。
CAM5–6 保留 SFP 视频显示，运动记录的两个 ABI 槽固定为零。
原始视频、CAM1–4 FIR、DDR 和 PCIe 图像路径继续输出完整 RGB565 帧。
该基线没有启用 FPGA NPU；运动信息可供 RK3568 侧识别程序选择区域或
安排推理，但静止目标仍需周期性全帧识别。

## 检测结果

- 每路图像 640×480，横纵每隔 4 像素采样，保存 160×120 字节灰度历史。
- 灰度为扩展 RGB565 后的 `(R+2G+B)/4`，与上一完整源帧比较。
- 差值 ≥16 的采样点计为变化；每块至少 8 点变化才标记运动。
- 网格 16×12，每块对应原图 40×40 像素。192 位位图按行排列，
  bit `y*16+x` 对应块 `(x,y)`。
- 区域边界是运动块的最小外接矩形，端点包含在内。像素范围为
  `[minx*40, (maxx+1)*40-1] × [miny*40, (maxy+1)*40-1]`。
- 首个完整帧仅建立参考，比较有效位为 0；之后有效位为 1。
  短帧、额外尾部像素和队列溢出触发参考恢复；异常标志随后续完整结果发布。
- 一次记录属于最新源帧。它不具有显示 DDR 帧标签的对应保证。

核心在采样接受后的第 1 拍注册差值判定和块选择，第 2 拍更新块内计数、
位图和区域；帧尾后的第 2 拍发布结果。帧尾后第 1 拍的新帧起始合法，
工作状态延迟清零，首个新像素最早在帧尾后第 2 拍接受。
适配器先注册 `{start,end,valid,RGB}` 事件，再给核心提供帧尾排空周期。
最后一个像素发出为 T 时，核心帧尾在 T+2、结果发布在 T+4、记录捕获在
T+5，下一次核心起始最早 T+6；持续无丢帧处理需要每帧至少 5 个空白时钟。
六路完整图像显示不等待运动结果，异常检测帧按恢复规则重新建立参考。

## 寄存器页

所有地址以 16 字节对齐，每次执行独立 16 字节事务，数值在低 32 位。
必须在同一个 DMA 锁内完成一次完整快照读取，并使用独立 DMA scratch，
避免覆盖图像缓冲。候选查看器使用 `0x3FE000`；帧标签 scratch 为 `0x3FF000`。

| 地址 | 含义 |
|---|---|
| `0x20000800` | selector：bit31 写 1 冻结；bits10:8 为相机 0–3；bits3:0 为字 0–9；4–5 为保留零记录 |
| `0x20000810` | 冻结记录中所选的 32 位字 |
| `0x20000820` | 快照 generation，每次有效相机冻结递增 |
| `0x20000830` | magic `0x4D4F5431` |
| `0x20000840` | 几何 `0x01E00280`，高半字高度，低半字宽度 |
| `0x20000850` | 配置 `0x0C102804`，从高到低为行数、列数、块边长、步长 |

先写 `0x80000000 | (camera<<8)`，读取 generation；逐字写
`(camera<<8)|word` 并读 data；最后重读 generation，确认未变化。
普通 selector 写入不会刷新快照。非法相机冻结保持原快照及 generation，
非法索引读取为 0。

| 字 | 字段 |
|---|---|
| 0 | 源帧序号，包含后来被丢弃的帧起始，按 32 位回绕 |
| 1 | bit0 比较有效，bit1 区域有效，bit2 帧异常 |
| 2 | bits7:0 运动块数；bits23:8 变化采样数 |
| 3 | 从低到高四个 nibble：minx、maxx、miny、maxy |
| 4–9 | 192 位位图，从低 32 位到高 32 位 |

## 构建和验收

PDS 工程入口为 `work/project.pds`，厂商流程更新 `work/flow.pds`。
必须串行执行厂商工具，不能同时启动 PDS GUI。IP 和约束保持基线字节。
详细命令见 `BUILD.md`，主机 ABI 和构建说明见 `host/camview/README.motion.md`。

`status.json` 的 `complete` 仅代表构建检查及 bit 生成通过，不代表烧录和
运行验收完成。烧录、六路截图和实时结果必须分别保留证据；验收清单在
`../../log/100h_motion/deliverable_checklist.md`。

候选查看器以 `CAMVIEW_MOTION=1` 显示 CAM1–4 运动状态，每秒读取这四路快照；
日志包含序号、块数、变化采样数、区域、异常标志和 48 位十六进制位图。
继续保持 `CAMVIEW_SWAP_INTERVAL=0`。原查看器、启动环境和基线 bit
均保留，发生显示或 DMA 异常时恢复基线。
