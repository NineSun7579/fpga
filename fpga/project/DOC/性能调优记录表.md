## 三、TIMESTAMP 四节点打点方案 (已实现, prep_regs +0x170~0x17C)

```
TS0 采集完成  ──→ ts_cap_pulse  (ov5640 帧完成, 已同步到 pclk)
TS1 预处理完成 ──→ ts_prep_pulse (preprocess_top 帧尾)
TS2 NPU 完成  ──→ ts_npu_pulse  (npu done, 已同步)
TS3 DMA 完成  ──→ ts_dma_pulse  (CH0 帧搬运完成)
```
读数: 主机读 0x170~0x17C; 相减得各段延迟; 写 0x17C 清零。
节拍: TICK_DIV 参数 (默认 50 → 1µs@50MHz), 32 位循环 ~71 分钟。
