# OV5640 一帧图像 → RK3568 完整传输链路

基于 top.v / pcie_fifo.v / ov5640_ddr_w_ctrl.v 实际接线整理 (2026-09-09)。
分辨率按 1280×720 RGB565 (1.8MB/帧, 30fps ≈ 53MB/s) 举例。

## 0. 总览

```
OV5640传感器 ═DVP═> cmos_capture ─> ov5640_cdc ─> ov5640_ddr_w ──AXI──┐
 (pclk域)         (像素装配)      (跨时钟域)      (成帧/乒乓)          │ S01
                                                                      ▼
                                                              axi_crossbar_7x3
                                                                      │ M00
RK3568 ◄══PCIe═══ ips2l_pcie_dma ◄── pcie_tx_fifo ◄── AXI读(arid=0) ──┤
 (LPDDR4)          (tx_top引擎)      (跨时钟域)                        ▼
                                                                    DDR3
        ①主机编程DMA描述符(BAR寄存器) ②DDR帧地址 ③硬件搬运 ④MSI/轮询通知
```

## 1. 逐级链路

### ① 光信号→DVP 并行口（OV5640 传感器，片外）
- 传感器按 SCCB 预置寄存器输出 RGB565：`cmos1_pclk`(~42MHz) + `cmos1_vsync` +
  `cmos1_href` + `cmos1_data[7:0]`（一字节/拍，一个像素传 2 拍）
- 配置链路：上电后 `ov5640_i2c_rgb565_cfg.v` 经 `cmos1_scl/sda` 自动写传感器寄存器

### ② DVP 采集与像素装配（`cmos_capture.v`，pclk 域）
- 按 vsync 定位帧头、href 定位行有效，把相邻两字节装配成 16bit 像素
- 产物：`cmos_frame_data[15:0]` + 行/场有效打点，输出速率 = pclk/2

### ③ 跨时钟域（`ov5640_cdc.v`，pclk → axi_clk）
- 异步 FIFO：写侧 pclk，读侧 axi_clk（50MHz 系统时钟）
- 摄像头与系统时钟**无频率整数关系**，此处必须异步 FIFO（CDC 纪律）

### ④ 成帧与乒乓管理（`ov5640_ddr_w.v` + `ov5640_ddr_w_ctrl.v`，axi_clk 域）
- 把像素流攒成 AXI 突发（`cam_data_len`×16 beat）
- **乒乓双缓冲**：`w_ping` 逐帧翻转，奇数帧写 `cam_data_addr_1`，偶数帧写
  `cam_data_addr_2`——写帧 N 时读帧 N-1 互不干扰
- 帧写完置 `s_xdma_req[1:0]` 对应位 = "该缓冲有完整新帧"标志
- 输出标准 AXI4 写主：`ov5640_axi_awaddr/wdata/wvalid...`

### ⑤ 交叉矩阵（`axi_crossbar_7x3`，axi_clk 域）
- S01(摄像头) → M00(DDR3) 端到端；与 S00(PCIe 主机)、S02~ 同时仲裁
- 写入通道：DDR3 控制器 IP（`ddr3`，top.v L243）收 `ddr_axi_*` 完成写

### ⑥ DDR3 存储（物理芯片）
- 帧落在 `cam_data_addr_1` 或 `_2` 指向的物理区间（乒乓）
- 此刻起，这一帧对 PCIe 主机"可见"——但**没人通知主机**（现状缺口，见 §4）

### ⑦ 主机取帧路径 A：主机拉（Memory Read，最简单）
```
RK3568 驱动 → PCIe Memory Read TLP (目标 = FPGA DDR 帧地址)
  → PCIe IP (pango_pcie_top) → AXI 读 (crossbar S00→M00) → DDR3
  → axi_rdata → Completion TLP → RK3568 LPDDR4 缓冲
```
- 主机知道乒乓基址后，轮询/交替读两块缓冲即可拿帧；无硬件参与

### ⑧ 主机取帧路径 B：FPGA 推（DMA，高吞吐，推荐）
```
1) 主机经 BAR 写 DMA 描述符: 源=FPGA DDR 帧地址, 长度=1.8MB, 主机目的地址
2) ips2l_pcie_dma_controller 启动 → 发 AXI 读 (arid=0, crossbar M00→DDR3)
3) pcie_fifo.v:747  axi_rdata(rid==0) → pcie_tx_fifo (axi_clk → pclk_div2 跨域)
4) 水位达标 (pcie_fifo.v:538 fpga_data_ready) → ips2l_pcie_dma_tx_top
   → PCIe MemoryWrite TLP 流 → txp/txn 差分对
5) RK3568 RC 收 TLP → 写入驱动预分配的 DMA 缓冲 (LPDDR4)
6) 完成: fpga_tx_done / MSI 中断通知主机
```

### ⑨ RK3568 侧落地
- 驱动层：DMA 缓冲（CMA/UIO mmap）映射到用户态
- 应用层：拿到 1.8MB RGB565 帧 → 显示/送 NPU/红绿灯判别

## 2. 带宽与时序账

| 段 | 带宽 | 时钟域跨越 |
|---|---|---|
| ①→② DVP | 53 MB/s | - |
| ③ CDC FIFO | 53 MB/s | pclk → axi_clk |
| ⑤→⑥ AXI 写 | 53 MB/s (峰值远高) | - |
| ⑧ DMA 推 | 按需, 峰值 ~1.2GB/s | axi_clk → pclk_div2 (tx_fifo) |
| PCIe 物理层 | Gen2 x4 ≈ 1.6GB/s 理论 | - |

## 3. 现状与缺口

| 环节 | 状态 |
|---|---|
| ①~⑥ 摄像头→DDR | RTL 完整, 参与布线, 原设计主通路 |
| ⑦/⑧ DMA 通路 | RTL 完整, 参与布线; 链路训练/寄存器编程序列待上板 |
| 帧同步 | ❌ 缺: `s_xdma_req`/乒乓标志没有导出到 PCIe 寄存器, 主机不知道 |
|   | "哪块缓冲是完整的帧"—— 建议把 w_ping + 帧计数接入 prep_regs (PIPE_STATUS) |
| 预处理插入点 | ④→⑤ 之间 (写 DDR 前处理) 或 ⑦/⑧ 读出后 (读侧处理), 见集成指南 |

## 4. 最小验证清单 (上板)

1. 示波器/LED 确认 `cmos1_pclk` 与 vsync 存在
2.ILA/PAP_MARK_DEBUG 抓 `s_xdma_req` 翻转 → 证明帧持续写入 DDR
3. 主机经 PCIe 读 `cam_data_addr_1` 区间 → 数据随画面变化
4. 切到路径 B (DMA 推) → 3568 缓冲收到整帧 → 链路闭环
