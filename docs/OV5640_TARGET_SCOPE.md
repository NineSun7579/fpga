# OV5640 产品目标与迁移边界

更新日期：2026-09-01

## 决策

摄像头 HDMI 产品目标已由 owner 校正为 OV5640，最终运行在实际焊接 `PG2L50H-6IFBG484` 的 `RK3568+PG2L50H100H` 开发板上。现有 `41_ov7725_hdmi/`、顶层 `ov7725_hdmi` 及 O0/O1/O2/M3-A 构建、STA、CDC/RDC 记录继续作为 OV7725 legacy 历史证据，不改名冒充 OV5640 实现或验收结果。

owner 提供的只读参考位置为：

```text
webdav/100h.rar/100h/59_top_dual_ov5640_hdmi
```

该参考工程当前未导入仓库，尚未验证其器件、顶层、单/双摄像头范围、DDR3、HDMI、时钟、约束和 IP 版本。参考工程中的 PG2L100H 生成物不得用于 PG2L50H 签核或烧录。

## 禁止直接继承

现有 OV7725 legacy 使用 `7'h21` SCCB 地址、8 位寄存器地址、OV7725 RGB565 配置表和 640x480 输入假设。这些事实只描述旧工程，不是 OV5640 的接口或寄存器依据。在 OV5640 模组资料和参考工程完成审核前，不修改活动 RTL、IDF、FDC、RCF 或 canonical 构建输入。

## 迁移任务

1. **C0 参考工程只读审计**：导入到 staging，登记全部源文件、IP、约束、顶层、器件元数据和绝对路径，不直接覆盖现有工程。
2. **C1 产品范围冻结**：审核单摄或双摄、模组料号、MCLK、RESET/PWDN、I/O 电压、管脚、DVP 位宽和极性、输出格式、分辨率、帧率与字节序。
3. **C2 项目边界设计**：确定新的项目目录与顶层，形成 OV5640 SCCB/寄存器配置、读 ID 自检、采集、DDR3 帧缓存和 HDMI 输出的源/IP/FDC 迁移方案。
4. **C3 PG2L50H 实现**：所有 IP 在 `Logos2 / PG2L50H / FBG484 / -6` 下重新审核或生成，完成七阶段 PDS 构建和严格 gate；旧 100H STA、SDF、网表和位流全部不可继承。
5. **S3 Questa 验证**：使用已确认的 Questa Sim-64 `2021.1`，建立 OV5640 项目级自检 TB、相对路径 filelist/DO，依次关闭行为级、综合后、PNR 后功能和 PNR 后时序仿真。

## 仿真与保密门槛

- 公共 Questa、Logos2 USIM/VSIM 和原语 smoke 已通过，不等于 OV5640 项目通过。
- 每级测试必须有 watchdog、失败 `$fatal`、非零失败退出和唯一 `TEST PASS`。
- PNR 后时序仿真必须确认 SDF 真实标注到项目 DUT 层级。
- 仿真器安装目录通过运行参数提供；许可证路径、服务器、feature、内容和许可证文件不得进入 tracked 文件或日志证据。
