# 紫光盘古100Pro 外部输入清单

更新日期：2026-09-02

当前统一目标：开发板“紫光盘古100Pro”，FPGA `PG2L100H-6IFBG484`，PDS
`Logos2 / PG2L100H / FBG484 / -6`。在以下一手资料归档前，不授权烧录，也不把历史
PG2L50H/PG2L100H 产物视为当前验收证据。

## 必需资料

1. FPGA 丝印照片或等价一手记录，以及板卡原理图版本和 BOM。
2. 配置 bank 电压、启动模式、share pin 使用条件。
3. DDR3 颗粒完整料号、数量、容量、rank、x16/x32 组织、速率、地址/数据映射、参考时钟和电气参数。
4. PCIe x2 lane 映射/极性、100 MHz refclk、PERST#、AC 耦合、连接器拓扑、SCBV 和 UART/LED 决策。
5. 两只 OV5640 模组完整料号；每路 MCLK、RESET、PWDN、SCCB、DVP 位宽/极性、供电电压、输出格式、分辨率、帧率、字节序，以及左右拼接规则。
6. HDMI 输出模式、像素时钟、TMDS 管脚和电气标准。

## 验收方式

- 每项资料必须注明来源、版本或照片编号，并能映射到项目证据表。
- 资料冻结后，重新生成匹配 PG2L100H 的 IP/FDC/RCF，完成 PDS 七阶段、STA、Questa 四级仿真和产物器件交叉检查。
