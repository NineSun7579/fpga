# 独立RK3568环视工具

六路身份按用户澄清：C1/C2同向前双目、C3左、C4右、C5/C6同向后双目，四个方位。前后各选一眼，另一眼作为新帧备用，不再拆成不同朝向。

环绕HUD：六张480p纹理由GPU进行虚拟视线投影，相邻有效重叠区羽化，支持鼠标水平/垂直拖动和滚轮视场角调整。投影先在640×480帧缓冲完成再放大，避免CPU整幅全景约4FPS的瓶颈。

俯视HUD：地面四点单应矩阵与镜头参数组成逆向映射缓存，后台OpenCV采样及融合；画面中央独立绘制车辆轮廓和前方箭头。1/2或Tab在模式间切换。

标定界面：逐路方向、俯仰、滚转和FOV；源图和统一地面画布四点拖动；JSON导入/保存/应用；保存非同步的六路固定标定截图与时间清单。缺少标定时两种视图都有明确提示，实际距离和接缝几何尚未认证。

采用合理且在3568可运行的独立实现：OpenGL ES2针孔/鱼眼投影、缓存单应逆映射、几何有效区羽化、受限曝光补偿和按帧年龄渐退。参考开源项目与链接位于../surround360_src/OPEN_SOURCE_REFERENCES.md；没有引入Jetson CUDA、外部车辆资产或别的车辆标定。

软件验证完成：最终Qt/OpenCV构建、CPU数学/采集合成自检、实际Mali上的合成显示与交互、完整离线软件GL交互。当前最终真实六路结果与驱动健康以driver_check/为准。
