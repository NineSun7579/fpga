# 用户澄清后的正确输入模型

| 输入 | 物理模块 | 朝向 | 当前环视策略 |
|---|---|---:|---|
| C1 / C2 | 同向前双目 | 0° / 0° | C1优先，C2新帧备用 |
| C3 | 左摄像头 | −90° | 使用C3 |
| C4 | 右摄像头 | +90° | 使用C4 |
| C5 / C6 | 同向后双目 | 180° / 180° | C5优先，C6新帧备用 |

四个观察方位，六条输入流。没有本机双目外参、镜头标定与同步数据时，每组只选一眼；选中的摄像头参与图像和几何权重，未选眼不进入融合分母。这样不会把双目两眼误当成两个宽视角相机，也不会直接叠加同一对象产生额外双眼重影。

主眼完全新鲜时优先；主眼开始老化且备用更鲜时改选备用；两眼失效时保留该方位的几何区域但图像渐退到黑。其他方位正常显示。

这仍是未标定的四方位预览。双目可用于深度，但需要真实基线、R/T、K/D和同步验证，本次不捏造这些参数。此前错误的−27/+27和−153/+153配置备份后停用；旧布局截图与性能记录不作为最终几何验收。

最终修正已通过八组CPU引擎自检及11项GPU着色器读回检查。测试数据表明前C1正常时输出C1颜色，缺失时输出C2；后组同理C5/C6。未选眼不影响曝光求解，地面投影使用同向对应区域。实际Mali与真实输入结果详见RESULT.md及binocular/目录。
