# 独立RK3568 360环视工具结果

已实现独立程序surround360，两种HUD可切换：480p GPU环绕视图（鼠标拖动和滚轮缩放）及360地面俯视图。对应同向前双目C1/C2、左C3、右C4、同向后双目C5/C6。

当前没有双目标定，前组优先C1、备用C2；后组优先C5、备用C6。每组只选一眼进入投影和几何分母，避免误增视野或叠加两眼重影。实际C5未持续更新，C6承担后方画面。

算法为针孔/鱼眼视线投影、几何有效区羽化、受限曝光匹配、按帧年龄渐退，俯视使用缓存地面单应逆映射。GPU环绕在640×480帧缓冲完成后放大显示，OpenCV俯视在后台处理。没有NN依赖。参考与许可证链接见[开源参考](../surround360_src/OPEN_SOURCE_REFERENCES.md)。

已通过采集数学/合成检查、环视引擎检查、实际Mali着色器、两模式切换、鼠标拖动和标定窗口验证；最终实机检查使用更正后的同向双目配置。旧错误朝向布局的截图已作废。

安装程序`/userdata/surround360/surround360`；配置`/userdata/surround360/calibration.json`；源码`/userdata/linaro/surround360-work/`。程序SHA256：`a3ab21fd66925cd71d5460e2bbd0a607afc864dc8814ae5e07ecea0ed8f9f94d`。

`1/2`或`Tab`切换HUD；鼠标拖动环绕方向，滚轮调整视场角；`C`打开标定，`S`截图，`F`全屏，`Q`退出。标定面板支持逐路参数、源/目标地面四点拖动、JSON配置与非同步标定图采集。

驱动已恢复实际DMA、中断计数随传输增加，当前五路持续更新；C5仅静态帧。测试用原驱动重载/PCIe重扫恢复，未改驱动源代码或FPGA。超时根因和永久恢复条件尚未证明。

环视和detview独占同一采集设备，测试后恢复原detview。独立运行：退出detview后`sudo -E bash /userdata/surround360/run_surround360.sh`；退出环视后用`restore_detview.sh`恢复。

所有默认标定标志保持false。无实测镜头/地面对应点时，接缝和俯视几何只是近似预览，不可据此测距离；竖直物体和近物可能拉伸/重影。双目深度还需真实R/T、K/D及同步输入。

[标定指南](../surround360_src/CALIBRATION_GUIDE.md)：由用户完成棋盘格采图、K/D计算与导入、方位校正、地面四点及独立点验收。未替用户标定，配置标志仍为false。
