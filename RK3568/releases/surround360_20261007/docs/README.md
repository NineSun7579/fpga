# RK3568 六路360环视工具

独立于detview的应用，复用既有PCIe帧缓冲读取协议，不调用NPU。摄像头方位为C1/C2同向前双目、C3左、C4右、C5/C6同向后双目，四个观察方位。

未提供双目标定时，每组双目选一路参与环视，另一路作为缺帧备用：前组优先C1、备用C2；后组优先C5、备用C6。两眼不会被假设成不同朝向或直接叠加；没有测量基线和双目外参时不声称生成深度或消除近物视差。
新输入配置的朝向为`0/0/−90/+90/180/180`。此前开发期间的分离朝向配置已停用，旧布局截图不作为当前几何结果。

两种视图：GPU直接投影六路480p输入的可拖动环绕窗口，以及地面投影的360俯视视图。切换不重启采集。相邻摄像头按有效投影区域羽化融合，旧帧渐退；无数据区域保持暗色，不以长期冻结帧伪装实时画面。CPU全景拼接路径保留用于算法检查；实机环绕显示使用GPU，避免在CPU上逐帧生成整幅全景图。

当前没有实际镜头/安装标定，默认角度和地面投影仅用于交互预览。未标定提示会一直显示；它们不代表真实车辆周围尺寸、无接缝效果或可信距离。视觉差异、镜头畸变、光轴方向、缺少视场重叠以及不同步画面均会影响拼接。俯视变换只对选定地面平面成立，直立物体仍会拉伸。

## 构建与启动

```sh
qmake surround360.pro
nice -n 10 make -j1
QT_QPA_PLATFORM=offscreen ./surround360 --selftest
sudo -E ./surround360 --fullscreen --config /userdata/surround360/calibration.json
# 无设备演示/验证
./surround360 --synthetic --fullscreen
```

六路采集设备由一个查看器独占；先正常退出detview/camview再打开此工具。工具不自动改驱动或FPGA寄存器。退出后可重新打开原查看器。

## 操作

鼠标拖动环绕视图旋转，滚轮调整视场角。`1`环绕、`2`俯视、`Tab`切换模式、`C`标定、`S`截图、`F`全屏、`Q/Esc`退出。HUD按钮提供相同操作，六路状态卡显示输入帧率/画面年龄。

标定编辑可选择摄像头、调整环绕方向和视场角，并拖动地面四点。源点与目标点顺序必须对应；选择可见平面特征点，按远左、远右、近右、近左。采集图片可供棋盘格/鱼眼镜头离线标定，镜头参数可由配置文件导入。保存配置后重新加载可复现投影。步骤见[标定流程](CALIBRATION_WORKFLOW.md)。

算法与配置接口见README_ALGORITHMS.md；实际参考的开源项目见OPEN_SOURCE_REFERENCES.md。提供方开源实现作为算法参考，应用代码独立实现。
GPU直接投影实现见[GPU说明](README_GPU.md)，共享板端的启动/恢复说明见[部署说明](DEPLOYMENT.md)。
完整操作步骤见[标定指南](CALIBRATION_GUIDE.md)，由用户采集照片并完成测量，当前没有替用户标定。
