# 从预览到实际拼接

当前C1/C2为同向前双目、C3左、C4右、C5/C6为同向后双目。双目两眼朝向相同，不做左右角度拆分；各组实际视场角、基线和外参仍需标定。

当前环视每组只采用一眼，并在该眼停止更新时选另眼。双目融合或深度需要该组真实的K/D、两眼相对R/T和同步图像；四点地面映射不能替代双目标定。

未标定俯视预览采用四个稍重叠的方位区域，而不是六个窄扇区。其预览坐标仍不能作为实际地面尺寸使用，完成标定后由各路实测地面四点取代。

1. **先检查方位和镜头。** 环绕视图拖动到各方向，查看相邻输入是否真的有重叠。C键打开面板，逐路调整水平朝向、俯仰、滚转和视场角。没有重叠时羽化无法填补缺失区域。
2. **采集镜头标定图片。** 面板保存的是打开时的固定六路图及时间清单，不保证各摄像头曝光同步。多次摆放棋盘格，覆盖图像中央与边缘；按针孔/鱼眼镜头选择OpenCV标定模型，得到各路K及D。导入配置后面板用校正图选择地面点。
3. **选同一地面坐标系。** 在车辆周围地面放置已知对应关系的标记，源图四点和目标地面四点顺序一致。目标画布坐标必须对六路共享同一尺度和原点；仅凭任意拖点只能做视觉调整，不能证明距离准确。
4. **保存并应用。** 配置文件原子写入，映射在后台重新构建。保持未完成的标定标记为未标定；复制别的相机K/D、示例四点或仅创建JSON文件不会自动使画面标为已标定。
5. **验证保留点与接缝。** 用没有参与拟合的地面标记检查映射；近物和竖直物仍可能产生拉伸/重影。车辆不同摄像头有视差，方向标定不能代替真实深度重建。

工具提供手动地面点和配置入口；棋盘格数据仍需实际拍摄，未使用示例标定冒充本机标定。需要硬件同步或更好的重影处理时，必须先确认相机曝光/传输同步关系。
