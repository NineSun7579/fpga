# 环视工具验证口径

1. CPU数学检查：摄像头身份/方位、RGB565颜色、标签轮转及新旧帧判断、投影和归一化融合、地面单应变换、标定文件有效性、缺帧与过期帧。
   方位按0/0/−90/+90/180/180验证：前后双目各一眼参与投影，另一眼只作备用；同组两眼不会扩大视场或重复计入融合分母。主眼缺帧时备用眼输出正常，两眼均失效时该方位渐退。
2. 板端合成样例检查：两种视图生成、真实Mali着色器、模式切换和鼠标拖动事件、GPU截屏。合成样例不代表真实标定效果。
3. 六路实机检查：独占已有采集设备，记录每路输入帧率/年龄和错误；分别保存环绕、俯视实际画面，记录处理和显示速度。
4. 未标定状态明确显示，俯视图片不用于实际距离/位置测量。默认视场角和地面四点只是预览参数；摄像头之间真实平滑几何需要镜头标定、地面对应点及实测安装方向。
5. 缺帧摄像头不阻塞整体画面。输入停止后渐退，暗区表示当前没有新图像，不以历史帧长期填补。
6. 保存原detview命令行，测试失败恢复；新工具正常运行时由它独占PCIe，旧detview源码/程序/模型不改动。

此工具不调用NPU。合成映射缓存复用，OpenCV处理在后台线程，HUD/鼠标交互独立于合成帧率。图像暂存仅保留最新帧，禁止形成等待队列。
