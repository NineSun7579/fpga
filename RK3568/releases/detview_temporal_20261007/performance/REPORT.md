# 瞬态检测框过滤：RK3568 性能验证

结论：最终版本常规视频显示帧率与旧版相当，未观察到由过滤引起的明显掉帧或长暂停。多框压力测试发现并修复了 ARM long double 软件运算造成的额外开销。这个结论适用于本次视频与配置，不等同于保证任何输入都无卡顿。

同一 MVP_accuracy_round1 模型、同一 480p30 视频循环、全屏、--no-tracking；每组 100 秒，前 30 秒预热，统计第 30–90 秒，截图在第 95 秒。CPU 保留 ondemand，NPU 保留 performance 900 MHz，所有 governor 测前测后相同。无并发查看器、推理或编译任务进入统计窗口。各组一次测试，不能将小幅差异解释成统计显著提升。

统计窗口超过 100ms 的推理完成间隔：旧版 1 次，最终版 5 次；超过 250ms：旧版 0 次，最终版 0 次。所有解码采样成功，无恢复/模型错误。

绘制指标取现有约 5 秒的 display-stage 日志，按统计窗口重叠权重聚合，完整覆盖 60 秒。P95 是各重叠分段直方图 P95 上界的最大值，并非整段精确 P95。最大值属于重叠分段。new_paint_fps 指真正新视频帧绘制，与 swap_fps 分开；输入是 30 fps，不能称为 60 fps 无丢帧。推理完成间隔并非屏幕帧间隔，现有日志未逐帧记录屏幕间隔。应用采用最新帧策略，未显示的源帧不能全归于过滤。CPU 100% 表示一个核心。

过滤核心压力测试使用实际 float 坐标结构、同一类别、30 次预热及 500 次记录。计时含 process 与 visible，独立于 NPU/Qt，CPU governor 不变。grid 为分散框，all_overlap 为所有框重叠的人工极端输入；该输入通常会被同类 NMS 大幅消除，不能代表正常模型输出。这里只覆盖 300 个稳定历史目标，不宣称涵盖 600 历史轨迹的每种组合。

优化对 float 坐标使用 double 计算 IoU，避免 AArch64 long double 软件运算；更宽泛坐标类型保留原安全路径。过滤策略仍为同类 IoU≥0.25、连续 3 次有效推理观察确认、无跟踪时保留 180ms。最终版同时修正：真实漏检后保留期结束，重新出现必须重新连续确认；持续被低帧率模型匹配的目标保留其观察历史。板上最终 float 118 项和全部 8 个应用自检通过；父会话已验证宽泛坐标回退路径及 10,000 多帧 float 重放一致。上述核心压力测试发生在消失后重新确认修正之前，稳定框工作负载的 IoU 与排序算法未变化，最终性能结论取最新源码的实际视频复测。

最终常驻预览不带 --shot 或 --duration，关闭自动 GL 截图，避免此前观测到的约 0.55 秒截图停顿。30 秒部署验证中的截图只用于留证，不属于性能统计或常驻预览。源码与二进制均保留回退备份；模型 SHA256 未变化。未改 FPGA、捕获驱动、模型阈值、校准或 NMS。
